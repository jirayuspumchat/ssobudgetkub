# เข้าใจงบ ประกันสังคม

**เปิดงบบริหารงานสำนักงานประกันสังคม ปีงบประมาณ 2563–2567 ให้คนทั่วไปอ่านเข้าใจได้ในหน้าเดียว**

แปลงเอกสาร PDF ราชการ 6 ฉบับ เป็นข้อมูลที่เครื่องอ่านได้ แล้วเรียบเรียงเป็นกราฟและคำอธิบาย
ทุกตัวเลขมีเลขหน้าของเอกสารต้นทางกำกับ ตรวจย้อนกลับได้ และดาวน์โหลดไปใช้ต่อได้ฟรี

## เว็บไซต์นี้ตอบอะไร

คนมักได้ยินคำว่า "งบประกันสังคม" แล้วสับสนว่าหมายถึงเงินก้อนไหน เพราะเงินที่เกี่ยวกับ
ประกันสังคมมี 3 ส่วนที่ขนาดต่างกันมาก เว็บนี้พาดูส่วนที่เล็กที่สุด คือ
**งบที่สำนักงานใช้ในการทำงานและดูแลสำนักงาน** ซึ่งปี 2567 อยู่ที่ 5,303 ล้านบาท
หรือราว **0.2%** ของเงินลงทุนกองทุนประกันสังคม (2.66 ล้านล้านบาท ณ 31 ธันวาคม 2567)

| ปีงบประมาณ | จัดสรร | รวมเบิกจ่ายและผูกพัน | อัตราเบิกจ่าย | ตัดยอด ณ |
|---|---:|---:|---:|---|
| 2563 | 4,420.52 ล้านบาท | 3,954.80 ล้านบาท | 89.46% | 31 ม.ค. 2564 |
| 2564 | 5,798.71 ล้านบาท | 5,283.72 ล้านบาท | 91.12% | 31 ม.ค. 2565 |
| 2565 | 5,528.46 ล้านบาท | 5,332.47 ล้านบาท | 96.45% | 31 ธ.ค. 2565 |
| 2566 | 6,938.49 ล้านบาท | 6,613.63 ล้านบาท | 95.32% | 29 ก.พ. 2567 |
| 2567 | 5,303.08 ล้านบาท | 4,180.81 ล้านบาท | 78.84% | 31 ต.ค. 2567 |

> **อ่านอัตราเบิกจ่ายอย่างระวัง** — แต่ละปีตัดยอดห่างจากสิ้นปีงบประมาณไม่เท่ากัน
> ปี 2567 ตัดยอดหลังสิ้นปีงบเพียง 1 เดือน ขณะที่ปี 2566 ตัดยอดหลังสิ้นปีงบ 5 เดือน
> การเทียบ 78.84% กับ 95.32% ตรง ๆ จึงไม่ยุติธรรมกับปี 2567

## เนื้อหาบนหน้าเว็บ 8 บท

| บท | หัวข้อ | สิ่งที่ได้เห็น |
|---|---|---|
| — | **เงิน 3 ส่วน ต่างกันอย่างไร** | ภาพเทียบขนาดเงินลงทุนกองทุน เงินสิทธิประโยชน์ และงบบริหารงาน พร้อมการ์ดอธิบายแต่ละก้อน |
| §1 | **รู้จัก 3 คำหลักก่อนเริ่มอ่านงบ** | แถบสัดส่วน "จัดสรร / รวมเบิกจ่ายและผูกพัน / คงเหลือ" และคำอธิบายว่า "ผูกพัน" คืออะไร |
| §2 | **ปี 2567 เบิกจ่ายได้ 78.84% — ตัวเลขนี้บอกอะไร** | กราฟแท่ง 5 ปี กดแท่งปีไหนก็ได้เพื่อไปดูโครงสร้างงบปีนั้น พร้อมกล่องอธิบายวันที่ตัดยอด |
| §3 | **งบก้อนนี้แบ่งยังไง** | Treemap และแท่งแนวนอน เจาะลงได้ 4 ระดับ: แผนงาน → กลุ่มรายจ่าย → หมวดงบรายจ่าย → หมวดค่าใช้จ่าย |
| §4 | **ลองทายก่อนว่าเงินไปไหน** | การ์ดให้ทายยอดงบก่อนเฉลย และหน้าต่างรายการงบทั้งหมด 1,305 รายการ กรองตามปีและหมวดได้ |
| §5 | **รายจ่ายประจำ เป็นงบที่ต้องใช้ต่อเนื่อง** | Sparkline แนวโน้ม 5 ปีของ 507 รายการที่จับคู่ข้ามปีได้ แยกกลุ่มรายการที่มีทุกปีกับรายการปีเดียว |
| §6 | **ซื้อมา 5,419 ล้าน เหลือมูลค่าตามบัญชี 1,133 ล้าน** | ทะเบียนสินทรัพย์ 82,021 รายการ ณ 30 ก.ย. 2567 เทียบราคาที่ได้มากับมูลค่าคงเหลือ 13 หมวด |
| §7 | **อ่านงบยังไงไม่ให้พลาด** | แบบทดสอบ 5 ข้อเรื่องกับดักการอ่านตัวเลข พร้อมคำอธิบายรายข้อ |
| §8 | **ตรวจย้อนกลับได้ทุกตัวเลข** | รายการเอกสารต้นทางทั้ง 6 ฉบับ และปุ่มดาวน์โหลดข้อมูล 8 ตาราง (CSV/JSON) |

จุดที่ตั้งใจทำเป็นพิเศษ

- **ทุกตัวเลขมีป้ายที่มา** — ป้ายสีเทาบอกเลขหน้าของ PDF ต้นทาง ส่วนตัวเลขจากแหล่งอื่น
  (เงินลงทุนกองทุน และเพดาน 10% ตาม พ.ร.บ.ประกันสังคม พ.ศ. 2533 มาตรา 24) ใช้ป้ายสีทองพร้อมลิงก์
- **ไม่มีไลบรารีภายนอก** — กราฟทุกตัววาด SVG เองด้วย JavaScript ล้วน ไม่มี build step ไม่มี CDN
- **เข้าถึงได้** — ใช้คีย์บอร์ดได้ทุกส่วน มี ARIA ครบ รองรับโหมดมืดและสว่าง มีโหมดพิมพ์
  และปิด animation ทั้งหมดเมื่อระบบตั้ง `prefers-reduced-motion`
- **ชุดสีผ่านการตรวจ** — ยึด CI ของสำนักงานประกันสังคม (น้ำเงิน `#005C9E` + ทอง `#FFC324`)
  ตรวจ lightness band, chroma floor และการแยกสีสำหรับตาบอดสี ทั้งสองธีม
- **เปิดแบบไฟล์เดียวได้** — `web/index.standalone.html` รวม HTML, CSS, JS และข้อมูลไว้ในไฟล์เดียว

## เปิดดูเว็บไซต์

`index.html` ต้องเปิดผ่าน HTTP เพราะโหลด `data.js` กับ `app.js` เป็นไฟล์แยก

```bash
python -m http.server 8777 --directory web
```

แล้วเปิด <http://localhost:8777>

ถ้าอยากได้ไฟล์เดียวจบ ดับเบิลคลิก `web/index.standalone.html` ได้เลย ไม่ต้องมีเซิร์ฟเวอร์
และไม่ต้องต่อเน็ต (ฟอนต์อยู่ใน `web/fonts/` แล้ว) แต่ต้องวาง `fonts/`, `logo-light.png`,
`logo-dark.png` และ `flashthink-white.png` ไว้ข้าง ๆ ไฟล์เสมอ

## 5 กติกาที่ต้องรู้ก่อนนำข้อมูลไปใช้

ข้อเหล่านี้ไม่ใช่คำแนะนำ แต่เป็นกติกาที่ถ้าไม่ทำตามแล้วตัวเลขจะผิด

1. **รวมยอดจากรายการย่อยสุดเท่านั้น** — กรอง `เป็นรายการย่อยสุด == 'ใช่'`
   ห้ามใช้ `เป็นแถวสรุป == 'ไม่ใช่'` เพราะจะนับซ้ำเกินจริง **568–794 ล้านบาทต่อปี**
2. **ช่องว่างไม่ใช่ศูนย์** — ต้นฉบับพิมพ์ขีดไว้ แปลว่าไม่มีข้อมูล อย่าเติมศูนย์อัตโนมัติ
3. **ห้ามคำนวณ `คงเหลือ` ใหม่** — มี **529 แถว** ที่ จัดสรร − เบิกจ่าย ไม่เท่ากับ คงเหลือ ตามต้นฉบับ
   ชุดข้อมูลนี้ยึดค่าที่พิมพ์มา และบันทึกไว้ใน `data_quality_checks.csv` แทนการแก้ค่า
4. **`หมวดค่าใช้จ่าย` ชื่อซ้ำข้ามสาขา** — ต้องคีย์ด้วย path เต็ม ไม่ใช่ชื่อเดี่ยว
   (เช่น "ค่าใช้สอย" ปี 2567 โผล่ 4 ครั้งใต้แผนงานคนละอัน)
5. **ก่อนเทียบแต่ละปี ดูว่านับยอดถึงวันไหน** — คอลัมน์ `เดือนหลังสิ้นปีงบ` มีให้แล้วในไฟล์งบรายปี

## สร้างข้อมูลใหม่เมื่อ dataset เปลี่ยน

```bash
python web/build_data.py --inline
```

สคริปต์จะ **ตรวจยอดก่อนเขียนไฟล์** ถ้าไม่ตรงจะหยุดและไม่เขียนอะไรเลย

- ผลบวกรายการย่อยสุดของแต่ละปี เท่ากับยอดรวมใน `budget_annual_summary.csv`
- ผลบวกแผนงานระดับบนสุด เท่ากับยอดรวมรายปี
- ยอดสินทรัพย์รวมตรงกับรายงานตรวจใน `outputs/csv_audit_2026-09-11/report_th.md`
- ราคาที่ได้มา บวก ค่าเสื่อมสะสม เท่ากับ มูลค่าตามบัญชี

ตัด `--inline` ออกถ้าไม่ต้องสร้าง `index.standalone.html` ใหม่

### การรวมรายการที่สะกดชื่อต่างกัน

เอกสารต้นฉบับสะกดชื่อรายการเดียวกันไม่ตรงกันข้ามปี (เช่น `ปลดดภัย` กับ `ปลอดภัย`
หรือ `KGS` กับ `KTBGS`) **ระบบไม่รวมให้อัตโนมัติ** เพราะบางคู่ที่ชื่อคล้ายกันถึง 94.6%
เป็นคนละเรื่องจริง ๆ การรวมผิดจะทำให้ประวัติงบของรายการนั้นผิดไปทั้งเส้น
ทุกการรวมจึงต้องมีคนตัดสินกำกับ

```bash
python dataset/scripts/build_merge_candidates.py   # อัปเดตรายชื่อคู่ที่ต้องตัดสิน
# แก้ dataset/manual_merge.csv ด้วยมือ (ต้องกรอกคอลัมน์ ผู้ตัดสิน)
python web/build_data.py --inline                  # รวมตามคำตัดสิน
```

รายละเอียดทั้งหมดอยู่ใน [web/README.md](web/README.md)

## ความโปร่งใสของข้อมูล

โปรเจกต์นี้ไม่ได้ซ่อนจุดที่ข้อมูลต้นฉบับไม่สอดคล้องกัน แต่บันทึกไว้ทั้งหมด

- `dataset/data_quality_checks.csv` — 28 รายการตรวจ ระบุจำนวนแถวที่มีปัญหา ค่าสูงสุด
  เลขหน้าอ้างอิง และการจัดการ (ทุกรายการคือ "บันทึกไว้ ไม่แก้ไขค่า")
- `outputs/csv_audit_2026-09-11/report_th.md` — รายงานตรวจ CSV 13 ไฟล์ 146,847 ระเบียน
- `outputs/pdf_full_audit_2026-09-11/evidence/` — ภาพครอปจากหน้า PDF จริง
